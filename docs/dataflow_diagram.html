这是当前控制链和性能分析的关键边界。

2.4 设计方向推荐 & 不推荐

✅ 推荐采用

#方向原理 & 收益
①K/V-Stationary当前 KV head 在 URAM 驻留，4 个 Q heads 共享同一次 K/V DMA。
②Q 流式加载Q 只遍历一次，每 tile 从 DDR 加载后立即消费。省 512 KB URAM。
③MAC 分时复用同一逻辑阵列做 Q×K^T + A×V；v2.2 post-route 使用 163 DSP。
④流式数据通路S_tile 和 P_tile 不写回 SRAM，MAC→Softmax→MAC 全流水直通。
⑤QKV 投影在主机端投影计算量大 (1000× Attention)，放在 ARM/软件。FPGA 只做 Attention。
⑥GQA group 循环L≤512: 当前 KV head 驻留并被 4 个 Q heads 复用；L>512: 分页/分块尚未实现。
⑦分块计算FlashAttention 基础 — 整个设计的前提。

❌ 不推荐

#方向不推荐原因
⑧稀疏注意力改变模型输出，不符合 "aligned with Llama3-8B specification"。
⑨模型量化bf16 硬性要求，计算精度不可降。
⑩QKV投影+Attention 融合投影计算量 = 1000× Attention，融合使 MAC 无资源做 Attention。
⑪大 MAC 阵列违反 "DSPs as fewer as possible"；DDR 跟不上时 MAC 空转。
⑫权重常驻 FPGAWq 32 MB 物理上装不进片上存储；权重无需进入 Attention 路径。

2.5 FlashAttention 分块循环 & 时序分析

以一个 GQA 组为例（4 Q heads + 1 KV head），L=512, Tq=32, Tk=64：

// ===== 阶段 1: 当前 GQA group 的请求驱动加载 =====
CSR_LOAD_REQ → host 选择 group/head → 显式启动 K DMA 和 V DMA
DDR → URAM: K_group[0..511][0..127] bf16  // 当前 KV head，128 KB
DDR → URAM: V_group[0..511][0..127] bf16  // 当前 KV head，128 KB

// ===== 阶段 2: Attention 双层循环 =====
for q_start in [0, 32, 64, ..., 480]:              // 16 次 Q tile 迭代

    // Q 流式加载 (DDR → Ping-Pong Buffer)
    DDR_LOAD: Q[q_start:q_start+32][0..127]         // 8 KB, ~0.5 μs

    // Online Softmax 状态初始化
    m[0..15] = -inf;  l[0..15] = 0;  O_acc = 0  // two 16-row microtiles form TILE_Q=32

    for kv_start in [0, 64, 128, ..., 448]:           // 8 次 KV tile 迭代

        // K/V 从 URAM 读取 (无 DDR 开销!)
        URAM_READ: K[kv_start:kv_start+64][0..127]     // 16 KB, ~10 ns (多bank并行)
        URAM_READ: V[kv_start:kv_start+64][0..127]     // 16 KB, ~10 ns

        // Phase A: Q×K^T
        S_tile[32,64] = Q_tile × K_tile^T              // 262K MACs, ~1024 cycles @ 256 MAC/cycle

        // Phase B: Online Softmax + A×V (流式直通)
        S_scaled = S_tile / √128 + mask
        for i in 0..31:                                  // 32 行并行
            m_new[i] = max(m[i], row_max(S_scaled[i,:]))
            P_row[i] = exp(S_scaled[i,:] - m_new[i])   // EXP LUT, 1 cycle/element
            l[i] = l[i]×exp(m[i]-m_new[i]) + sum(P_row[i])
            O_acc[i,:] = O_acc[i,:]×exp(m[i]-m_new[i]) + P_row[i] × V_tile

    // 归一化 + 写回
    O_tile[0..31][0..127] = bf16(O_acc[0..31][0..127] / l[0..31])
    DDR_WRITE: O_tile                                  // 8 KB, ~0.5 μs

// ===== 当前签收时序（post-route） =====
// 不再用固定 DDR 带宽估算签收性能；请读取 driver/Vivado counter
// 一个 group 的 K/V 传输为 256 KB，随后服务 4 个 Q heads
